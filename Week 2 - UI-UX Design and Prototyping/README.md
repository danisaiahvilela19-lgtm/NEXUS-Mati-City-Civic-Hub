# NEXUS — Week 2: UI/UX Design and Prototyping

## Overview

During Week 2, the team focused on designing the NEXUS mobile application using Figma. The goal was to establish the application's visual identity, screen layouts, and user experience before proceeding to mobile application development.

## Activities and Accomplishments

- Created high-fidelity (Hi-Fi) mobile application screen designs.
- Established a consistent visual style and color palette.
- Developed the main user flow for reporting community issues.
- Designed the report submission process:
  1. Select Category
  2. Location & Photo
  3. Review & Submit
- Planned the navigation and layout of the main application screens.
- Developed a reusable Design System.
- Prepared the Figma prototype to demonstrate the application's user flow.

## Week 2 Focus

- High-Fidelity UI Design
- Design System
- User Flow
- Figma Prototyping

Week 2 established the visual foundation and interactive design flow of the NEXUS mobile application. The completed UI/UX designs and Figma prototype serve as the reference for the mobile application development phase.
