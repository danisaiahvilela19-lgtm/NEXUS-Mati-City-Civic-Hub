# NEXUS: Mati City Civic Hub
## User Flow

*SDG Alignment:* SDG 11 — Sustainable Cities and Communities

### 1. Purpose

This user flow illustrates how residents can use NEXUS to report community issues, track report status, and discover environmental initiatives in Mati City.

### 2. Community Issue Reporting Flow

1. Open the NEXUS application.
2. View the Home Dashboard.
3. Select "Report an Issue."
4. Choose an issue category, such as waste management, road damage, or streetlight problems.
5. Enter the issue details and provide the required information.
6. Submit the report.
7. View the submission confirmation.
8. Open "My Reports" to track the report status.
9. View updates when authorized personnel update the report.

### 3. Environmental Initiatives Flow

1. Open the NEXUS application.
2. View the Home Dashboard.
3. Select "Environmental Initiatives."
4. Browse available environmental programs and community activities.
5. Select an activity to view its details.
6. Follow the provided participation instructions.

### 4. Report Status Flow

A submitted report may progress through the following statuses, depending on the implemented workflow:

- *Submitted* — The report has been sent through the app.
- *Under Review* — Authorized personnel are reviewing the report.
- *In Progress* — Action is being taken on the reported issue.
- *Resolved* — The issue has been marked as resolved.
- *Rejected* — The report was not accepted, with a reason provided where possible.

### 5. Expected Outcome

The user flow is designed to make community issue reporting easier, provide visibility into report progress, and help residents discover environmental activities. Actual status updates depend on the availability and participation of authorized personnel.
