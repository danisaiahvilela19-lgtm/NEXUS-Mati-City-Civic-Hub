# NEXUS – Design System

## Overview

The NEXUS Design System establishes the visual identity and reusable UI components of the Mati City Civic Hub mobile application.

## Design System Components

- Color Palette
- Typography
- Buttons
- Input Fields
- Icons
- Cards and UI Components
- Spacing and Layout

## Design Tool

Figma

## Purpose

To maintain a consistent, accessible, and user-friendly interface throughout the NEXUS mobile application.
