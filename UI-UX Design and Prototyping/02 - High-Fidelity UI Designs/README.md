# NEXUS – High-Fidelity UI Designs

## Overview

The High-Fidelity UI Designs represent the visual interface of the NEXUS – Mati City Civic Hub mobile application.

These designs transform the initial low-fidelity wireframes into detailed mobile application screens with consistent colors, typography, layouts, and reusable UI components.

## Main UI Design Features

- Home Screen
- Community Issue Reporting
- Category Selection
- Location and Photo Attachment
- Review and Submit
- My Reports
- Report Details
- Notifications
- User Profile

## Design Tool

Figma

## Purpose

To provide a complete visual reference for the development of the NEXUS mobile application.
