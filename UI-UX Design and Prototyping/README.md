# NEXUS — Week 2: UI/UX Design and Prototyping

## Overview

During Week 2, the team focused on designing the NEXUS mobile application using Figma. The goal was to establish the application's visual identity, screen layouts, and user experience before moving into development.

## Activities and Accomplishments

- Created high-fidelity (Hi-Fi) mobile application screen designs.
- Designed the NEXUS interface using a consistent visual style and color palette.
- Developed the main user flow for reporting community issues.
- Designed the report submission process:
  1. Select Category
  2. Location & Photo
  3. Review & Submit
- Planned the navigation and layout of the main application screens.
- Worked on the Design System to establish reusable design elements.
- Prepared the Figma prototype for demonstrating the application's user flow.

## Week 2 Focus

- High-Fidelity UI Design
- Design System
- User Flow
- Figma Prototyping
