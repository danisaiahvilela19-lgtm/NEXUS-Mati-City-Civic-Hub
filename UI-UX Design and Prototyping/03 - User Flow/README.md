# NEXUS – User Flow

## Overview

The NEXUS User Flow illustrates how users navigate through the mobile application, particularly when reporting community issues in Mati City.

## Community Issue Reporting Process

1. Open the NEXUS application.
2. Navigate to the Home Screen.
3. Select Report an Issue.
4. Choose an Issue Category.
5. Provide the Location and attach a Photo.
6. Review the Report Details.
7. Submit the Report.
8. View the submitted report under My Reports.
9. Track the report status.

## Main User Flow

Home Screen → Report an Issue → Select Category → Location & Photo → Review & Submit → My Reports → Track Status

## Purpose

To provide users with a simple and organized process for reporting community concerns through the NEXUS mobile application.
