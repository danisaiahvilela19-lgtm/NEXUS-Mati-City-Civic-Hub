# NEXUS – Figma Prototype

## Overview

The NEXUS Figma Prototype demonstrates the planned navigation and interaction flow of the Mati City Civic Hub mobile application.

## Prototype Features

- Screen-to-screen navigation
- Home screen interactions
- Community issue reporting flow
- Category selection
- Location and photo submission
- Report review and submission
- My Reports navigation

## Design Tool

Figma

## Purpose

To demonstrate the intended user experience and navigation of the NEXUS mobile application before and during development.
